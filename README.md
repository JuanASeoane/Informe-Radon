# 📊 Generador de Informes PDF desde Excel

Una aplicación web profesional construida con Streamlit que genera informes PDF a partir de archivos Excel con análisis estadístico y visualizaciones.

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-2C2D72?style=for-the-badge&logo=pandas&logoColor=white)

## ✨ Características

- 📤 **Carga de archivos**: Soporte para archivos Excel (.xlsx, .xls)
- 👁️ **Vista previa**: Visualización inmediata de los datos cargados
- 📊 **Análisis estadístico**: Estadísticas descriptivas automáticas
- 📈 **Visualizaciones**: Gráficos integrados (barras, histogramas, dispersión)
- 📄 **Generación de PDF**: Informes profesionales con formato
- 🎨 **Personalización**: Títulos, autor, notas y opciones de contenido
- 📱 **Responsive**: Interfaz adaptable a cualquier dispositivo
- ⚡ **Rápido**: Procesamiento eficiente de datos
